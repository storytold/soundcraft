Choose **File > New...** to start a session, then **Track > New...** to add tracks. Save with **File > Save Session**.

## Create a session

1. Choose **File > New...**.
2. In the **New Session** window, type a **Name** and pick a **Sample Rate**.
3. Click **Create**.

Tick **Start from the demo session** only if you want the built-in demo song instead of an empty session. If the session that is open has unsaved changes, SoundCraft asks whether to save them first.

## Add tracks

1. Choose **Track > New...**. The **New Tracks** window opens.
2. Set how many tracks to **Create** (1 to 128).
3. Pick the channel format, for example Mono. The window starts with Mono.
4. Pick the kind of track. The list includes **Audio Track**, **Aux Input**, **MIDI Track**, **Instrument Track**, **VCA Master**, **Routing Folder Track** and **Video Track**.
5. Pick **Samples** or **Ticks** for the timebase, and type a **Name:**.
6. Click **Create**.

## Save the session

1. Choose **File > Save Session**.
2. The first time, the **Save Session As** window asks for a path. Type one or click **Browse…**. The file name ends in `.scraft`.
3. Click **OK**. If a session file with that name already exists, the window asks whether to replace it and the button becomes **Replace**.

To open a session later, choose **File > Open > Session...**.
