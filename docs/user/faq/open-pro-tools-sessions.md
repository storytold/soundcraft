title: Can SoundCraft open Pro Tools sessions?
description: SoundCraft cannot open Pro Tools .ptx or .ptf sessions, or AAF and OMF files, yet. Export your audio files and bring them in.
order: 20
verified: 0.7.0
---

No. SoundCraft does not read Pro Tools `.ptx` or `.ptf` sessions, and it does not read or write AAF or OMF yet. Its own session format is `.scraft`.

## What you can do

1. Get the audio as files, for example WAV.
2. In SoundCraft, use **File > Import > Audio...** for each file. See [Import audio](../guides/import-audio.md).
3. For MIDI, use **File > Import > MIDI...**. SoundCraft reads Standard MIDI Files.
