Yes. SoundCraft is one of the Crafting Apps, which the project describes as free, open-source creative tools from the ArtCraft team. The code is dual-licensed under MIT or Apache-2.0, at your option.

SoundCraft is pre-alpha. See the [home page](../index.md) for what is still missing.
