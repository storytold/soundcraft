# Serial output-path compensation

The renderer can align routes-only bus/Main output joins across serial Aux and Folder inserts. A leaf arrives after its supported active inserts; an Aux/Folder arrives after its input bus and its own inserts. Every output waits for the slowest producer of its destination. Main adds serial Master insert delays once; a selected bus removes only that bus's arrival time.

This uses the existing processing order. It does not compile another topology order. Any send slot, cycle/order violation, ambiguous ID, unsupported instrument or clip-effect path, unknown bus, unsupported geometry, latency overflow or refused bounded storage selects the entire existing compensation path. Muted send slots also select that fallback. Deep graphs whose existing bounded ordering is insufficient remain outside this guarantee.

Admission is limited to 1024 combined track/bus nodes, path/edge delays of at most 2^20 samples, and at most 2^24 f32 ring samples across output edges (64 MiB). Ring allocation is fallible before activation. An exact rejected projection is recorded before ring allocation: unchanged rejected blocks stay on legacy without retrying storage, while a changed topology/delay or explicit reset can retry. If even metadata capacity is unavailable, retained partial buffers retry at a node-count change or explicit reset. Raw latency, order-rank, edge and bus metadata use retained fallible scratch capacities. Identical projections reuse their metadata buffers and delay histories; topology/delay changes, compensation toggles and admitted/legacy transitions discard alignment histories without resetting processors. Ordinary processor tails and failure isolation remain in use.

This change preserves parameter-setter and processor block cadence, send behavior and render-position automation clocks. It does not establish send-edge compensation, processor-age automation, arbitrary graph compensation, allocation-free callbacks, prepared-workspace ownership or physical-device realtime acceptance. Initial/changed projection storage and changed histories may allocate during rendering; warmed identical projections do not allocate through the new PDC storage path. Whole-renderer workspace preparation remains separate work.

Synthetic impulse tests execute two/three-stage serial Aux/Folder paths, direct/bus joins, independent named-bus/Main head removal, unrelated delayed paths, serial Masters, PDC Off, first blocks and varied partitions. Additional cases exercise legacy fallback, isolated processor failure, reset/policy/route-history transitions and pure capacity arithmetic without allocating large rings. A warmed renderer test counts every capacity-growing reservation in this new PDC path and verifies stable metadata/ring addresses through repeated admitted and legacy blocks, plus an injected storage refusal with unchanged-block suppression and smaller-delay retry; it does not instrument unrelated renderer allocations. No installed hosted plugins are required.
