Unmodified regular and bold TrueType fonts from the Noto Project Authors,
licensed under the SIL Open Font License 1.1 (see `OFL.txt`).

Source: https://github.com/notofonts/noto-fonts/tree/ffebf8c1ee449e544955a7e813c54f9b73848eac/hinted/ttf/NotoSansThai

Embedded as fallback fonts for Thai text on every platform, including Web/WASM.
The license is also embedded in the About window for packaged distributions.
